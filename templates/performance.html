Module 3: Headline–Body Mismatch Detection (Consistency Alignment)
Methodology: TF-IDF Cosine Similarity with Validated Thresholding Decision Threshold τ = {{ eval_data.headline_body_mismatch_task.metrics.calibrated_threshold if eval_data.headline_body_mismatch_task else '0.100' }}

Unlike classification tasks with predefined ground-truth labels, mismatch detection was formulated as an alignment discrimination problem. The system measures TF-IDF N-gram cosine similarity between headlines and article bodies. A decision threshold was tuned on a validation set to maximize discrimination between matched pairs and synthetically shuffled pairs.
